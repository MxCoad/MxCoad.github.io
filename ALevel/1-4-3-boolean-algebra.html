1.4.3b

Simplifying with Boolean algebra

De Morgan's laws¬(A ∧ B) ≡ ¬A ∨ ¬B and ¬(A ∨ B) ≡ ¬A ∧ ¬B. "Break the line, change the sign": negate each term and swap ∧ and ∨.
DistributionA ∧ (B ∨ C) ≡ (A ∧ B) ∨ (A ∧ C) and A ∨ (B ∧ C) ≡ (A ∨ B) ∧ (A ∨ C)
Association(A ∧ B) ∧ C ≡ A ∧ (B ∧ C), and the same for ∨: brackets can be moved when the operators are the same.
CommutationA ∧ B ≡ B ∧ A and A ∨ B ≡ B ∨ A: order doesn't matter.
Double negation¬¬A ≡ A
AbsorptionA ∨ (A ∧ B) ≡ A and A ∧ (A ∨ B) ≡ A
Useful identitiesA ∧ 1 ≡ A, A ∧ 0 ≡ 0, A ∨ 1 ≡ 1, A ∨ 0 ≡ A, A ∧ A ≡ A, A ∨ A ≡ A, A ∧ ¬A ≡ 0, A ∨ ¬A ≡ 1

Worked example: simplify ¬(¬A ∨ B) ∨ (A ∧ B)

  1. De Morgan: ¬(¬A ∨ B) ≡ ¬¬A ∧ ¬B
  2. Double negation: ≡ A ∧ ¬B, so the whole thing is (A ∧ ¬B) ∨ (A ∧ B)
  3. Distribution (taking A out): A ∧ (¬B ∨ B)
  4. ¬B ∨ B ≡ 1, so A ∧ 1 ≡ A

1.4.3c

Karnaugh maps

A Karnaugh map is a grid version of a truth table, used to simplify expressions. The rows and columns are labelled in Gray code order (00, 01, 11, 10), so neighbouring cells differ by only one bit.

  1. Fill in the 1s from the truth table.
  2. Draw groups of 1s that are rectangles of size 1, 2, 4, 8 or 16 (powers of 2). No 0s may be inside a group.
  3. Make the groups as large as possible and use as few as possible. Groups may overlap and can wrap around the edges (and the four corners can form a group).
  4. For each group, write the variables that stay the same throughout it (A if always 1, ¬A if always 0). Variables that change are dropped.
  5. Join the groups' terms with ∨.

    1.4.3d

    Half adders and full adders

    Half adder

    • Adds two bits, A and B
    • Sum S = A ⊻ B (XOR gate)
    • Carry C = A ∧ B (AND gate)
    • Can't take a carry in, so can only add the rightmost bits

    Full adder

    • Adds three bits: A, B and a carry in
    • Made from two half adders and an OR gate
    • S = A ⊻ B ⊻ Cin
    • Cout = (A ∧ B) ∨ (Cin ∧ (A ⊻ B))
    • Full adders are chained (carry out to the next carry in) to add multi-bit numbers

    1.4.3e

    D-type flip-flops

    A D-type flip-flop stores one bit. It has a data input D, a clock input and an output Q. Q only changes on the rising edge of the clock (when it goes from 0 to 1): at that instant Q takes the value of D, and it then holds that value until the next rising edge, whatever D does in between.

    So it acts as memory: flip-flops are the building blocks of registers, and chains of them can make counters and shift registers.

    Try it: timing diagram

    Click along the D line to change the input. Dashed lines mark the rising edges — the only moments Q can change.

    Going further

    Using a clock edge rather than just "whenever D changes" means every flip-flop in the processor updates at exactly the same instant. Signals have time to settle between ticks, so the whole circuit moves from one stable state to the next — that's what the clock speed in 1.1.2 is counting.
