Spreadsheets: Paws & Claws
Animal Rescue

🐾 Your Mission

Paws & Claws Animal Rescue looks after animals until they find a new home. The rescue centre needs a spreadsheet to keep track of all the animals currently staying there. Your job is to build that spreadsheet from scratch. Work through Bronze first, then Silver, Gold, and Extension if you finish early.

💡
  • Open a new blank spreadsheet in Google Sheets.
  • Name your file as: PawsAndClaws_[YourName]
  • Read each step carefully before you do it — every step is explained fully.
  • The Formula Help Card at the bottom has every formula you will need.
  • You do not need to ask for help — everything is on this sheet.

🥈 Silver Use formulas to find out information
  • 1
    Leave row 10 blank as a gap. In cell A11, type the label: Total days (all animals)
  • 2
    Click on cell B11. You are going to type a formula to add up all the Days at Shelter values. Type exactly this:
    Type this formula in cell B11
    =SUM(E2:E9)
    This tells the spreadsheet: add up everything in column E, from row 2 to row 9. The answer should be 101.
  • 3
    In cell A12, type: Longest stay (days)
    In cell B12, type this formula to find the animal who has been there the longest:
    Type this formula in cell B12
    =MAX(E2:E9)
    MAX finds the biggest number in the range. The answer should be 30 — that is Pebble the cat!
  • 4
    In cell A13, type: Shortest stay (days)
    In cell B13, type a formula to find the animal who arrived most recently:
    Type this formula in cell B13
    =MIN(E2:E9)
    MIN finds the smallest number. The answer should be 3 — that is Noodle the cat!
  • 5
    Make the labels in column A (cells A11–A13) bold so they stand out.
✅

Check your work: B11 = 101, B12 = 30, B13 = 3. If you got different numbers, check you typed the formula exactly as shown — make sure you used a colon ( : ) not a dash.

⭐ Extension Finished early? Try these bonus tasks!
  • 1
    In cell A14, type: Average age (years)
    In cell B14, use this formula to find the average age of all the animals:
    Type this formula in cell B14
    =AVERAGE(C2:C9)
    AVERAGE adds all the numbers up and divides by how many there are. What is the average age? Does the answer surprise you?
  • 2
    Add a new column F. In cell F1, type the header: Needs Urgent Home?
    In cell F2, type this formula. It will write "YES ⚠️" for any animal that has been waiting more than 15 days, and "No" for animals that arrived recently:
    Type this formula in cell F2
    =IF(E2>15,"YES ⚠️","No")
    IF checks a condition. If the animal has been there MORE than 15 days, it writes YES ⚠️. Otherwise it writes No.
    Once you have typed it in F2, click on F2 and copy the formula down to F9 by dragging the small blue square in the bottom-right corner of the cell downwards.
  • 3
    Highlight the urgent animals. Select cells F2:F9. Use conditional formatting to make any cell that says "YES ⚠️" turn red. (Format → Conditional formatting → Text contains → YES)

🔑 Formula Help Card — Every formula you need is here

=SUM(E2:E9)

Adds up all the numbers in a range of cells. Change E2:E9 to whichever cells you want to add.

=MAX(E2:E9)

Finds the biggest (highest) number in a range. Useful for finding the longest stay.

=MIN(E2:E9)

Finds the smallest (lowest) number in a range. Useful for finding the shortest stay.

=AVERAGE(C2:C9)

Finds the mean average. Adds all the numbers together then divides by how many there are.

=IF(E2>15,"YES ⚠️","No")

Checks if something is true. If it is, writes the first answer. If not, writes the second answer.

Common mistakes

Always start a formula with =
Use a colon : between cell references, not a dash
Do not put spaces inside the formula
