Spreadsheets Challenge Sheet

📋 Your Mission

You have been hired as a junior data analyst for Velocity FC, a rising football club. The manager wants a professional spreadsheet to track player performance across the season. Your job is to build the spreadsheet from scratch, apply formulas, create charts, and present the data clearly. Work through the tasks below in order — Bronze first, then Silver, Gold, and Extension if you finish early.

💡
  • Open a new blank spreadsheet in Google Sheets or Microsoft Excel.
  • Save/Name your file as: Velocity_FC_[YourName]
  • Work through Bronze → Silver → Gold in order. Extension is a bonus challenge.
  • If you are stuck, check the Formula Help Card at the bottom of this sheet.
  • You do not need to ask for help — all the information you need is on this sheet.

Step 2 — Complete the Tasks
🥉 Bronze Data Entry & Formatting
  1. Type in all the data from the table above. Row 1 should be the header row with the column titles. Data starts from Row 2.
  2. Make the header row bold and give it a dark background colour with white text.
  3. Set all columns to an appropriate width so no text is cut off (you can double-click the column border to auto-fit).
  4. Add a thick border around the entire data table.
  5. In cell I1, type the label Goals per Game. In I2, write a formula to calculate Goals ÷ Games Played for the first player. Copy the formula down for all 10 players. Round your answers to 2 decimal places.
🥈 Silver Formulas & Summary Statistics
  1. Below your data (leave one blank row as a gap), create a Summary Statistics section. Label it clearly in bold.
  2. Use the correct formulas to calculate and label each of the following:
    Total Goals scored by all players
    Average Goals per player
    Highest number of Goals (any single player)
    Lowest number of Goals (any single player)
    Total Yellow Cards issued
    Total Red Cards issued
  3. In a new column H, add the header Contribution Score. For each player, calculate their score using this formula:
    // Goals × 3 + Assists × 2 − Yellow Cards − Red Cards × 3
  4. Sort the table by Contribution Score from highest to lowest so the best player is at the top.
🥇 Gold IF Statements, Conditional Formatting & Charts
  1. In a new column J, add the header Status. Use an IF formula so that:
    If Contribution Score ≥ 30 → display "Star Player"
    Otherwise → display "Squad Player"
  2. Apply conditional formatting to the Status column:
    • Cells showing "Star Player" → green background
    • Cells showing "Squad Player" → yellow background
  3. Create a bar chart showing each player's Contribution Score. Give the chart a title, label the axes, and make sure it is easy to read.
  4. Also apply conditional formatting to the Red Cards column — cells with a value greater than 0 should be highlighted in red.
⭐ Extension Advanced Challenge — Finished Early?
  1. Create a second sheet in the same file. Name it Position Analysis.
  2. On this new sheet, use COUNTIF to count how many players play in each position (Forward, Midfielder, Defender, Goalkeeper).
  3. Use SUMIF to calculate the total goals scored by each position group.
  4. Create a pie chart on this sheet showing the proportion of total goals scored by each position.
  5. Stretch: On the original sheet, add a new column Disciplinary Rating. Use a nested IF to rate each player:
    0 cards total → "Excellent"
    1–3 cards total → "Acceptable"
    4+ cards total → "Poor"
    (Hint: total cards = Yellow Cards + Red Cards)

🔑 Formula Help Card — All the formulas you might need

=SUM(C2:C11)

Adds up all values in a range of cells.

=AVERAGE(C2:C11)

Calculates the mean average of a range.

=MAX(C2:C11)

Finds the largest value in a range.

=MIN(C2:C11)

Finds the smallest value in a range.

=ROUND(C2/E2, 2)

Divides C2 by E2 and rounds the result to 2 decimal places.

=IF(H2>=30,"Star Player","Squad Player")

Displays one thing if the condition is true, another if false.

=COUNTIF(B2:B11,"Forward")

Counts how many cells in a range match a specific value.

=SUMIF(B2:B11,"Forward",C2:C11)

Adds up values in one column only where another column matches.
