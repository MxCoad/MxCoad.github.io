📋 Your Mission

The Velocity FC manager wants a Season Results Tracker. The club has played 10 matches this season, and you need to record the results, calculate points using formulas, and produce a chart showing how the team's points have grown over the season. The manager may also change the points system in the future — your spreadsheet must update automatically when he does.

🥉 Bronze Data Entry, Formatting & Goal Difference
  1. Enter all the match data from the table above. Row 1 should be the header row; data starts in Row 2.
  2. Format the header row: bold, dark background, white text, centred. Adjust column widths so all text is visible.
  3. Add a thick outer border around the whole data table.
  4. In cell F1, add the header Goal Difference. In F2, write a formula to calculate Goals For minus Goals Against. Copy it down for all 10 matches.
    =D2-E2
  5. Apply conditional formatting to the Goal Difference column (F2:F11):
    • Positive values → green background
    • Negative values → red background
🥈 Silver Result & Points — Using Nested IF
  1. In cell G1, add the header Result. In G2, write a nested IF formula to display "Win", "Draw", or "Loss" based on the goals:
    =IF(D2>E2,"Win",IF(D2=E2,"Draw","Loss"))
    Copy the formula down for all 10 matches.
  2. In cell H1, add the header Points. In H2, write an IF formula that awards points based on the result in column G:
    =IF(G2="Win",$L$1,IF(G2="Draw",$L$2,0))

  3. Why use $L$1 and $L$2? The dollar signs lock the cell reference so it always points to L1 (your "Points per Win") even when you copy the formula down. If you just used L1, it would shift to L2, L3, etc. as you copied down — giving the wrong answer. This is called an absolute cell reference.

    Copy the Points formula down for all 10 matches.
  4. Apply conditional formatting to the Result column (G2:G11): "Win" → green, "Draw" → yellow, "Loss" → red.
🥇 Gold Season Summary, COUNTIF & Line Chart
  1. In cell I1, add the header Cumulative Points. This tracks the running total of points after each match:
    • In I2: =H2
    • In I3 downwards: =I2+H3 — then copy down.
  2. Below your data (leave one blank row), create a Season Summary section. Use formulas to calculate and label:
    Total Points   → SUM of Points column
    Wins          → COUNTIF Result column for "Win"
    Draws         → COUNTIF Result column for "Draw"
    Losses        → COUNTIF Result column for "Loss"
    Goals Scored  → SUM Goals For column
    Goals Conceded→ SUM Goals Against column
    Total Goal Diff → SUM Goal Difference column
  3. Create a line chart using Match Number (column A) as the X axis and Cumulative Points (column I) as the Y axis. Give it the title "Points Accumulation — Velocity FC Season" and label both axes clearly.
  4. Test your absolute reference: Change the value in L1 from 3 to 2. Do all the Points and Total Points update automatically? Change it back to 3 when done.
⭐ Extension Home vs Away Analysis
  1. Create a second sheet named Home vs Away.
  2. Use COUNTIF to count how many Home matches were played and how many Away matches were played. (Hint: use the Venue column from Sheet 1 — you'll need to reference it as 'Sheet1'!C2:C11 or 'Results'!C2:C11 depending on your sheet name.)
  3. Use COUNTIFS (two conditions at once) to calculate:
    // How many Home Wins?
    =COUNTIFS(C2:C11,"Home",G2:G11,"Win")
    // How many Away Wins?
    =COUNTIFS(C2:C11,"Away",G2:G11,"Win")
    Do the same for Home Draws, Away Draws, Home Losses, Away Losses.
  4. Present your Home vs Away comparison in a neatly formatted table and add a clustered bar chart comparing Home and Away performance.

🔑 Formula Help Card

=D2-E2

Subtracts one cell from another. Use for Goal Difference.

=IF(D2>E2,"Win",IF(D2=E2,"Draw","Loss"))

A nested IF — checks two conditions in sequence to give one of three results.

$L$1 (absolute reference)

The $ signs lock the row and column. The reference won't shift when you copy the formula down.

=I2+H3

Running total (cumulative sum). Adds the new value to the previous running total.

=COUNTIF(G2:G11,"Win")

Counts how many cells in the range match the text "Win". Change the text for other results.

=COUNTIFS(C2:C11,"Home",G2:G11,"Win")

Counts rows where TWO conditions are both true — e.g. Venue is Home AND Result is Win.

Line Chart tips

Highlight column A and column I together (hold Ctrl/Cmd to select two columns), then Insert → Chart → Line.

Cross-sheet reference

To refer to another sheet, use: 'Sheet Name'!A1 — include the sheet name in single quotes if it has a space.
