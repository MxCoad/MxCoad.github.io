📖 Background — What are lookup functions?

Lookup functions let you search for a value in a table and automatically return related data. For example, if you type a student ID, a lookup function can find and display that student's name from a list.

VLOOKUP

Searches down a column (vertical). Use when your data is arranged in rows.

HLOOKUP

Searches across a row (horizontal). Use when your data is arranged in columns.

🥉 Bronze Task 2 — VLOOKUP: Find a Student's Name

The VLOOKUP syntax is:

=VLOOKUP(search_key, range, column_index, is_sorted)
search_key → what you are looking for
range → the table to search (e.g. A1:D6)
column_index → which column to return (1 = first, 2 = second...)
is_sorted → always use FALSE for exact matches
  1. Click on cell F1 and type the label: Search ID
  2. In cell F2, type a student ID: 103
  3. Click on cell G1 and type the label: Name Found
  4. In cell G2, enter this formula:
    =VLOOKUP(F2, A1:D6, 2, FALSE)
    Press Enter. You should see the name Chloe appear.
  5. Change the value in F2 to 101 — what name appears now?
Tip — Why column 2? We want to return the Name column, which is the 2nd column in our range A1:D6. Try changing 2 to 3 or 4 — what do you get?

🥇 Gold Task 4 — HLOOKUP: Search Across a Row

HLOOKUP works across rows instead of down columns. First, set up this new table starting at cell A9:

ABCDE
MonthJanFebMarApr
Sales12008501540920
Returns30124518

The HLOOKUP syntax is:

=HLOOKUP(search_key, range, row_index, is_sorted)
search_key → the column header you are searching for
range → the horizontal table (e.g. A9:E11)
row_index → which row to return (1 = first row, 2 = second...)
is_sorted → use FALSE for exact matches
  1. In cell A13 type: Month search
  2. In cell B13 type: Mar
  3. In cell A14 type: Sales result
  4. In cell B14 enter:
    =HLOOKUP(B13, A9:E11, 2, FALSE)
    You should see 1540 — the sales figure for March.
  5. Change B13 to Jan or Apr and observe the result.

🔑 Formula Help Card

=VLOOKUP(F2, A1:D6, 2, FALSE)

Searches down column A of the range for the value in F2, then returns the value from column 2 of that row.

=HLOOKUP(B13, A9:E11, 2, FALSE)

Searches across row 1 of the range for the value in B13, then returns the value from row 2 of that column.

column_index / row_index

Count from the start of your range, not from column A. If your range starts at B1, then B = 1, C = 2, and so on.

=IFERROR(formula, "Not found")

Wraps any formula. If the formula produces an error, it displays your chosen message instead.

Always use FALSE

The last argument controls matching. FALSE = exact match (almost always what you want). TRUE = approximate match (only for sorted data).

VLOOKUP vs HLOOKUP

VLOOKUP: your lookup values are in a column (vertical). HLOOKUP: your lookup values are in a row (horizontal).
