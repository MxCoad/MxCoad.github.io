Boolean logic

Computers are built from billions of tiny logic gates that work with just two values: 1 (true) and 0 (false). Learn the three gates, how to combine them into circuits, and how to complete truth tables.

2.4.1

AND, OR and NOT gates

A logic gate takes one or more binary inputs and produces a single binary output. A truth table shows the output for every possible combination of inputs.

2.4.1

Combining gates: logic diagrams

Gates can be joined so that the output of one gate is the input to another. A logic diagram shows the circuit; a Boolean expression describes it in words, using brackets to show which gate happens first.

For example, Q = (A AND B) OR NOT C: A and B go into an AND gate; C goes through a NOT gate; the two outputs go into an OR gate.

In the exam

When drawing a logic diagram, use the correct shape for each gate (they can't be just labelled boxes), connect each output to the right input, and label the inputs and the final output.

2.4.1

Truth tables for combined expressions

  1. Count the inputs. With n inputs there are 2n rows: 2 inputs → 4 rows, 3 inputs → 8 rows.
  2. List every combination by counting up in binary: 000, 001, 010, 011, 100…
  3. Add a column for each part of the expression (e.g. A AND B, then NOT C), working from the inside of the brackets outwards.
  4. Combine the columns to get the final output.

Mode

Common mistakes

  • Missing rows — always check you have 2n different combinations.
  • Ignoring brackets: NOT (A OR B) is not the same as NOT A OR B.
2.4.1

Solving problems with logic

Exam questions often describe a real situation. Turn each condition into an input letter, then link them with AND, OR and NOT.

Worked example

A security light (Q) turns on if it is dark (A) and movement is detected (B), or if the override switch (C) is on.

"Dark and movement" → A AND B. "…or the override" → OR C. So Q = (A AND B) OR C.

Check one row: dark (A = 1), no movement (B = 0), override on (C = 1) → (1 AND 0) OR 1 = 0 OR 1 = 1, so the light is on. ✓

Going further · grades 8–9

Different expressions can give identical truth tables. NOT (A AND B) gives exactly the same outputs as NOT A OR NOT B — try both in the truth table builder. This rule is called De Morgan's law, and engineers use rules like it to build circuits from fewer gates.
