01

Images & Sound — Sampling

J277 · 1.2.4 Data representation
Recap

IMAGESHow images are stored

  • Images are a grid of pixels. Resolution = width × height (how many pixels).
  • Colour depth (bit depth) = bits used per pixel. n bits → 2ⁿ colours.
  • More pixels or more colours = better quality but bigger file.
  • Metadata = data about the image (dimensions, colour depth, date, location…).
file size (bits) = width × height × colour depth

SOUNDHow sound is sampled

  • Sound is analogue — it must be converted to digital by sampling.
  • Sampling = measuring the wave's amplitude at regular intervals.
  • Sample rate = samples per second, measured in Hertz (Hz).
  • Bit depth = bits stored per sample. Higher rate/depth = closer to the original, bigger file.
file size (bits) = rate × bit depth × seconds

Describe how an analogue sound wave is converted into a digital file that a computer can store.
Award 1 mark each, max 3
  • The amplitude of the sound wave is measured…

Teacher checkpointTalk these through

  • KB or KiB? Decide as a class whether to divide bytes by 1000 or 1024 — and which your exam board's mark scheme expects.
  • Stereo: the sound formula above is for one channel. What changes for stereo? (× 2 channels.)
  • Stretch: why can't we just sample infinitely often? (Diminishing returns vs file size; human hearing limit ~20 kHz.)

The Need for Layers in Protocols

J277 · 1.3.1 Networks & protocols
Recap

WHATWhat a protocol & a layer are

  • A protocol is a set of rules for how devices communicate.
  • Network communication is split into layers, each with one specific job.
  • A layer only needs to talk to the layer directly above and below it.
  • Together the layers form a stack that gets a message from one device to another.

WHYWhy we bother with layers

  • Self-contained: one layer can be changed without breaking the others.
  • Manageable: a big problem is broken into smaller, simpler parts.
  • Standards: different manufacturers' hardware/software can work together.
  • Easier to fix: faults can be traced to a single layer.

Check yourself
Exam-style question
[2 marks]
State two reasons why network protocols are organised into layers.
Any two, 1 mark each
  • Breaks a complex task into smaller, manageable parts.
  • Each layer is self-contained / can be changed without affecting other layers.
  • Sets a common standard so equipment from different makers is compatible.
  • Makes faults easier to find and fix (you can isolate one layer).

Teacher checkpointTalk these through

  • The analogy: compare layers to a postal system — the writer doesn't care how the van drives; the driver doesn't read the letter. Each layer trusts the next.
  • Stretch: name the TCP/IP layers (Application, Transport, Internet, Link) and one protocol in each. Not required for every mark, but it lifts a top answer.
  • Common mistake: "layers make it faster" is not a marked benefit — push students to use the right vocabulary.

Differences Between Storage Devices

J277 · 1.2.3 Secondary storage
Recap · The three types

MAGNETICHDD, tape

  • Uses spinning platters & moving read/write heads.
  • ✔ Huge capacity, cheap per GB.
  • ✘ Slower; moving parts can break if dropped.
  • Best for: servers, backups, lots of cheap storage.

OPTICALCD, DVD, Blu-ray

  • A laser reads pits & lands on a disc.
  • ✔ Very cheap, light, portable.
  • ✘ Low capacity, slow, scratches easily.
  • Best for: distributing films/software cheaply.

SOLID STATESSD, USB, SD

  • Flash memory — no moving parts.
  • ✔ Fast, durable, silent, low power.
  • ✘ Dearest per GB; limited write cycles.
  • Best for: laptops, phones, cameras, anything portable.

Check yourself
Exam-style question
[3 marks]
A company needs to back up several terabytes of data every night as cheaply as possible. Identify a suitable storage device and justify your choice.
1 mark device + 2 marks justification
  • Magnetic storage (HDD or magnetic tape). (1)
  • It offers very high capacity, suitable for terabytes of data. (1)
  • It has the lowest cost per GB, meeting the "as cheaply as possible" requirement. (1)
  • (Accept: speed is less important as it runs overnight when nobody is using it.)

Teacher checkpointTalk these through

  • The golden rule for marks: a justification must link a property of the device to a requirement in the scenario — not just describe the device.
  • Durability vs reliability: draw out the difference (surviving a drop vs working consistently over time).
  • Stretch: why do SSDs eventually wear out? (Finite read/write cycles per cell.)
