Memory and storage

Where computers keep programs and data, how much space things take up, and how numbers, text, images and sound are all stored as binary. This is the biggest topic on Paper 1, and it's full of calculations, so practise with the tools.

1.2.1

Primary storage (memory)

Primary storage is memory the CPU can access directly. Computers need it because the CPU works far too fast to wait for secondary storage: programs and data that are currently in use are copied into primary storage so the CPU can fetch them quickly.

RAMRandom access memory Holds the programs and data currently in use, including the operating system. It can be read and written. It is volatile: its contents are lost when the power is switched off.
ROMRead-only memory Holds the start-up (boot) instructions — often called the BIOS — that the computer needs as soon as it is switched on. It is read-only, and it is non-volatile: its contents stay when the power is off.

Virtual memory

If RAM fills up, the operating system can use part of secondary storage (e.g. the hard drive or SSD) as virtual memory:

  1. Data or programs in RAM that aren't being used right now are moved out to virtual memory.
  2. That frees space in RAM for the data the CPU needs now.
  3. When the moved data is needed again, it is swapped back into RAM.

This lets the computer keep running more programs than RAM can hold — but it slows the computer down, because secondary storage is much slower than RAM. Adding more RAM reduces the need for virtual memory.

Common mistakes

  • Volatile means "loses its contents when the power is off" — not "unstable" or "can be changed".
  • Virtual memory is not "extra RAM" or "memory in the cloud". It's space on secondary storage used as if it were RAM.

Going further · grades 8–9

If a computer has far too little RAM, it can spend more time swapping data between RAM and virtual memory than doing useful work. This is called disk thrashing, and it's why an old computer slows to a crawl with lots of browser tabs open.

1.2.2

Secondary storage

Secondary storage is non-volatile storage that keeps programs and files permanently, even when the computer is off. It's needed because RAM is volatile and far too small to hold everything.

Choosing a device: the six characteristics

  • Capacity — how much it can store
  • Speed — how fast data can be read and written
  • Portability — how easy it is to carry (size, weight)
  • Durability — how well it survives knocks, drops or heat
  • Reliability — how consistently it works over time
  • Cost — usually compared per gigabyte

1.2.3

Units and file sizes

Computers store everything in binary because they are made of billions of tiny switches (transistors), each with only two states: on (1) or off (0).

BitA single binary digit: 0 or 1
Nibble4 bits
Byte8 bits
Kilobyte (KB)1,000 bytes
Megabyte (MB)1,000 kilobytes
Gigabyte (GB)1,000 megabytes
Terabyte (TB)1,000 gigabytes
Petabyte (PB)1,000 terabytes

To go up a unit, divide by 1,000 (or by 8 to go from bits to bytes). To go down, multiply.

File size formulas

Imagewidth × height × colour depth (in pixels and bits) = size in bits
Soundsample rate × bit depth × duration (in Hz, bits and seconds) = size in bits
Textbits per character × number of characters = size in bits

All three give an answer in bits — remember to divide by 8 to get bytes, then by 1,000 for kilobytes, and so on.

Worked example: storage needed

A student wants to store 200 photos of 3 MB each and 50 songs of 4 MB each. Total = (200 × 3) + (50 × 4) = 600 + 200 = 800 MB = 0.8 GB. So a 1 GB drive would just fit them; a 16 GB USB stick would leave plenty of room.

Common mistakes

  • Forgetting to divide by 8 — the formulas give bits, not bytes.
  • Using minutes instead of seconds in the sound formula.
  • Not showing your working — you can still get method marks if the final answer is wrong.

Going further · grades 8–9

Strictly, 1,024 bytes is a kibibyte (KiB) and 1,000 bytes is a kilobyte (KB). Operating systems often show sizes using 1,024 but label them "KB", which is why a "500 GB" drive shows up as about 465 GB on your computer.

1.2.4

Numbers: binary and hex

Binary ↔ denary

Each bit in an 8-bit binary number has a place value: 128, 64, 32, 16, 8, 4, 2, 1. Add up the place values that have a 1. With 8 bits you can store 0 to 255.

128  64  32  16   8   4   2   1
  1   0   1   1   0   1   1   0   = 128 + 32 + 16 + 4 + 2 = 182

To convert denary to binary, work from the left: if the place value fits into what's left, write 1 and subtract it; otherwise write 0.

Hexadecimal

Hex is base 16: digits 0–9 then A (10), B (11), C (12), D (13), E (14), F (15). One hex digit = one nibble (4 bits), so binary ↔ hex is easy: split the byte into two nibbles.

1011 0110
  11    6   →  B6

Hex ↔ denary: the left digit is worth 16s, the right digit 1s. B6 = (11 × 16) + 6 = 182.

Hex is used because it is shorter and easier for humans to read, remember and write than binary, with less chance of making mistakes — for example in colour codes like #FF8800 or MAC addresses.

Binary addition and overflow

Add from the right, carrying like in normal addition: 0+0 = 0, 0+1 = 1, 1+1 = 0 carry 1, 1+1+1 = 1 carry 1. If the answer needs more bits than are available (more than 255 for 8 bits), the extra carry is lost. This is an overflow error.

Binary shifts

A left shift moves every bit left and fills the gaps with 0s. Each place multiplies by 2. A right shift moves bits right; each place divides by 2. Bits shifted off the end are lost, which can make the answer wrong (overflow on a left shift, or losing the remainder on a right shift).

Common mistake

"Hex is used because it uses less memory" is wrong — the computer still stores it in binary. Hex is for humans: shorter, easier to read and fewer errors.

Going further · grades 8–9

Computers use shifts because they're far quicker than general multiplication. A right shift of an odd number loses the 1 at the end: 00010111 (23) shifted right 1 place gives 00001011 (11), not 11.5. That's a loss of precision.

1.2.4

Characters

Text is stored by giving every character a unique binary code. The full list of characters a computer can represent, with their codes, is called a character set.

ASCIIUses 7 bits per character, so 27 = 128 characters: English letters, digits, punctuation and control codes. (Extended ASCII uses 8 bits for 256 characters.)
UnicodeUses more bits per character (up to 32), so it can represent over a million characters — every writing system in the world, plus symbols and emoji. Its first 128 codes are the same as ASCII.

The more bits per character, the more characters can be represented (2bits) — but each character takes up more storage.

Codes are in logical order: 'A' is 65, so 'B' is 66, 'C' is 67… Lower-case 'a' is 97, and the digit '0' is 48. If you know one code you can work out the others.

Common mistake

The character '7' is not stored as the number 7 — in ASCII it is code 55. Characters and numbers are stored differently.

1.2.4

Images and sound

Images

A bitmap image is made of a grid of pixels (picture elements). Each pixel's colour is stored as a binary number.

  • Colour depth — the number of bits used for each pixel. More bits = more colours (2bits): 1 bit gives 2 colours, 8 bits give 256, 24 bits give over 16 million.
  • Resolution — the number of pixels in the image (width × height).
  • Metadata — extra data stored with the image, such as its width, height, colour depth, the date it was taken and the camera used. It's needed so the computer can display the image correctly.

Increasing the colour depth or the resolution improves the quality of the image but increases the file size.

Sound

Sound is an analogue wave. To store it, the computer samples it: it measures the amplitude (height) of the wave at regular intervals and stores each measurement as a binary number.

  • Sample rate — how many samples are taken per second, in hertz (Hz). CD quality is 44,100 Hz.
  • Bit depth — the number of bits used for each sample.
  • Duration — how long the recording is, in seconds.

A higher sample rate or bit depth means the digital version is closer to the original sound (better quality), but the file is bigger. A longer duration also means a bigger file. Use the calculator above to see the effect.

The GCSE Revision Console has an interactive sampling demo and more practice questions on images and sound.

Common mistake

Resolution is not "how clear the image is" — it's the number of pixels. Quality improves because of it, but the definition is the pixel count.

1.2.5

Compression

Compression makes files smaller. Smaller files take up less storage space, are quicker to send over a network or download, and use less bandwidth — useful for streaming and email attachments.

LossyPermanently removes some data — usually detail people are unlikely to notice. The original file cannot be fully recovered. Gives much smaller files. Used for photos (JPEG), music (MP3) and video streaming.
LosslessMakes the file smaller without losing any data: the original can be restored exactly. Files are not reduced as much. Used for text documents, program files and spreadsheets, where every bit matters (PNG and ZIP use lossless compression).

In the exam

When asked which to use, link it to the file: for a program or text file, lossless, because losing any data would break it or change its meaning. For a photo to send on social media, lossy, because a smaller file matters more than tiny details.

Going further · grades 8–9

One lossless method is run-length encoding (RLE): instead of storing WWWWWWBBBWW, store 6W 3B 2W. It works well when there are long runs of the same value, such as simple graphics, but can make files with lots of variation bigger.
