Programming fundamentals

The building blocks every program is made from. Examples use OCR's Exam Reference Language (ERL), which you'll see in the exam, with Python equivalents where they differ. Section B of Paper 2 asks you to write and fix code, so practise with the tools.

2.2.1

Variables, constants, input and output

VariableA named location in memory that stores a value which can change while the program runs.
ConstantA named value that cannot change while the program runs, e.g. const VAT = 0.2. If it needs updating, it only has to be changed in one place, and it can't be changed by accident.
AssignmentGiving a variable a value: score = 0, score = score + 10
InputData entered by the user: name = input("Enter your name")
OutputData shown to the user: print("Hello " + name)

Common mistake

= assigns a value; == compares two values. if score = 10 is wrong; if score == 10 is right.

2.2.1

Sequence, selection and iteration

Every program is built from three programming constructs:

  • Sequence — instructions carried out one after another, in order.
  • Selection — a decision chooses which code runs (if, switch).
  • Iteration — code is repeated (loops).

Selection

if mark >= 70 then
    print("Distinction")
elseif mark >= 50 then
    print("Pass")
else
    print("Fail")
endif

switch day:
    case "Sat":
        print("Weekend")
    case "Sun":
        print("Weekend")
    default:
        print("School day")
endswitch

Iteration

Count-controlled loops repeat a set number of times. Condition-controlled loops repeat until (or while) a condition is met, so you don't need to know in advance how many times.

// count-controlled: prints 0 to 9
for i = 0 to 9
    print(i)
next i

// condition-controlled: checked at the START (may run 0 times)
while answer != "yes"
    answer = input("Ready?")
endwhile

// condition-controlled: checked at the END (always runs at least once)
do
    guess = int(input("Guess"))
until guess == 7

Common mistake

for i = 0 to 9 runs 10 times, not 9 — ERL includes both ends. (Python's range(0, 10) stops before 10.)

2.2.2

Data types and casting

IntegerA whole number: 42, -7
Real (float)A number with a decimal part: 3.14, -0.5
BooleanOne of two values: true or false
CharacterA single letter, digit or symbol: "A", "7", "?"
StringA sequence of characters: "Hello", "SW17 0AQ"

Casting converts a value from one data type to another: int("42") → 42, str(42) → "42", real("3.5") → 3.5 (Python: float), bool → Boolean.

It matters because input() always returns a string. To do maths with what the user types, cast it first: age = int(input("Age?")).

Common mistake

Phone numbers and postcodes should be strings, not integers — you never do maths with them, and an integer would lose a leading 0.

2.2.3

Arrays and records

An array stores several values of the same data type under one name. Each value is accessed by its index, starting at 0. Arrays have a fixed size.

array colours[3]
colours[0] = "Red"
colours[1] = "Green"
colours[2] = "Blue"
print(colours[1])        // Green

// 2D array: like a table, [row, column]
array board[3, 3]
board[0, 2] = "X"

Arrays are usually processed with a for loop:

total = 0
for i = 0 to scores.length - 1
    total = total + scores[i]
next i

A record groups together related data of different types about one item — e.g. a pupil's name (string), age (integer) and whether they have a bus pass (Boolean). Each item of data is a field. In a database, each row of a table is a record.

Common mistake

The last index of an array of 10 items is 9, not 10. Looping to scores.length instead of scores.length - 1 goes past the end.

2.2.3

File handling and SQL

File handling

Files let a program save data permanently so it isn't lost when the program closes. Always open, then read or write, then close.

// reading every line
myFile = open("scores.txt")
while NOT myFile.endOfFile()
    print(myFile.readLine())
endwhile
myFile.close()

// writing
newFile("log.txt")
logFile = open("log.txt")
logFile.writeLine("Game over")
logFile.close()

SQL

SQL (Structured Query Language) is used to search a database. You need three keywords:

  • SELECT — which fields to show (* means all fields)
  • FROM — which table
  • WHERE — the conditions records must meet (optional)
SELECT name, score
FROM pupils
WHERE house = "Red" AND score > 50

2.2.3

Subprograms and random numbers

A subprogram is a named block of code that does one task and can be called from anywhere in the program. Data can be passed in as parameters.

Function — returns a value

function triple(n)
    return n * 3
endfunction

x = triple(5)   // x is 15

Procedure — doesn't return a value

procedure greet(name)
    print("Hello " + name)
endprocedure

greet("Sam")

Why use subprograms? The code can be reused without rewriting it; programs are shorter and easier to read; each subprogram can be tested separately; a large program can be decomposed and shared between programmers; and a fix only needs making in one place.

Random numbers

roll = random(1, 6) gives a random integer from 1 to 6 (inclusive) — useful for games and simulations. In Python: import random then random.randint(1, 6).

Going further · grades 8–9

A local variable is created inside a subprogram and only exists while it runs. A global variable (global score = 0) can be used anywhere. Local variables are safer: another part of the program can't change them by accident, and the same name can be reused in different subprograms.
