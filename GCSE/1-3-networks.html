Networks, connections and protocols

How computers are linked together, the hardware that does it, how the Internet finds websites, network layouts, and the rules (protocols) that let devices talk to each other.

1.3.1

LANs, WANs and performance

A network is two or more computers connected together so they can share data and resources such as files, printers and an Internet connection.

LANLocal area networkCovers a small geographical area, such as one building or site (a school, an office, a home). The hardware is usually owned and managed by the organisation that uses it.
WANWide area networkCovers a large geographical area, connecting LANs in different places — across a country or the world. It uses infrastructure (cables, satellites) owned by third parties such as telecoms companies. The Internet is the biggest WAN.

Factors that affect network performance

  • Bandwidth — the amount of data that can be sent per second. More bandwidth, faster network.
  • Number of users — more devices sharing the same bandwidth means less each, so it's slower.
  • Transmission media — fibre optic is faster than copper cable; wired is usually faster than wireless.
  • Error rate — data that arrives damaged has to be sent again, which slows things down.
  • Latency — the delay before data starts to arrive, e.g. because it has a long way to travel.
  • Interference — walls, distance and other devices can disrupt wireless signals.

Common mistake

A LAN isn't defined by the number of computers — a LAN can have thousands. It's about geographical area (and who owns the hardware).

1.3.1

Client–server and peer-to-peer

Client–server

One or more powerful servers provide services (files, email, websites, log-ins) and clients request them.

  • ✓ Files, back-ups and security managed centrally
  • ✓ Users can log in from any client
  • ✗ Servers are expensive and need a specialist to manage
  • ✗ If the server fails, clients lose access

Peer-to-peer (P2P)

All computers are equal. Each one stores its own files and shares them directly with the others.

  • ✓ Cheap and easy to set up — no server needed
  • ✓ No single point of failure
  • ✗ No central back-up or security; each user has to manage their own
  • ✗ Files are spread out and harder to find; a peer may be switched off

In the exam

Choose based on the scenario. A small business with three computers: peer-to-peer (cheap, simple). A school with hundreds of users: client–server (central log-ins, back-ups and security).

1.3.1

Network hardware

NICNetwork interface cardLets a device connect to a network (wired or wireless). Each NIC has a unique MAC address.
SwitchConnects devices within a LAN. It receives data and sends it only to the device it's meant for, using the MAC address.
RouterConnects different networks together, e.g. a LAN to the Internet. It forwards packets towards their destination using IP addresses.
WAPWireless access pointLets wireless devices connect to a wired network. (A home "router" is really a router, switch and WAP in one box.)
Transmission mediaWhat the data travels through: copper (Ethernet) cable — cheap, good for LANs; fibre optic cable — uses light, very fast, long distances, more expensive; radio waves for wireless.

Common mistake

Mixing up switches and routers. Switch: inside one network, uses MAC addresses. Router: between networks, uses IP addresses.

1.3.1

The Internet

The Internet is a worldwide collection of computer networks joined together. (The World Wide Web is the collection of websites you can reach over the Internet.)

DNSDomain name systemConverts a domain name (e.g. bbc.co.uk) into the IP address of the server that holds the website, because computers need the IP address to connect.
HostingStoring a website or files on a server connected to the Internet so others can access them, usually by paying a hosting company.
Web server & clientA web server stores web pages and sends them when asked. The client is the web browser that requests them.
The cloudUsing remote servers accessed over the Internet to store files or run software and services, instead of your own computer.

Cloud: advantages

  • Access files from anywhere, on any device
  • No need to buy or maintain your own servers
  • Easy to get more storage when needed
  • Back-ups and updates handled by the provider

Cloud: disadvantages

  • Needs an Internet connection
  • Data is stored by a third party — security and privacy concerns
  • Ongoing subscription costs
  • Less control over your data

No single DNS server knows every address. If yours doesn't have the answer, it asks other DNS servers in a hierarchy — starting with a root server, then the server for .com, then the one for example.com. Answers are cached for a while so the next look-up is faster.

1.3.1

Star and mesh topologies

A topology is the way the devices in a network are arranged and connected.

Star

Every device connects to a central switch.

  • ✓ If one cable or device fails, the rest of the network keeps working
  • ✓ Easy to add new devices
  • ✓ Fast: the switch sends data only to the right device
  • ✗ If the central switch fails, the whole network goes down
  • ✗ Needs a lot of cable

Mesh

Each device connects to several or all other devices (a full mesh connects every pair).

  • ✓ Many routes for data: if one link fails, data takes another route
  • ✓ No single point of failure
  • ✗ Lots of cable (in a wired mesh), so expensive
  • ✗ Complex to set up and manage

1.3.2

Wired and wireless connections

EthernetwiredUses cables. Fast, reliable and secure — it's hard to intercept data without physical access. But devices are tied to a cable, and cabling a building costs money.
Wi-FiwirelessUses radio waves. Devices can move around and it's easy to add new ones. But it's usually slower, affected by range and interference, and data can be intercepted more easily.
BluetoothwirelessConnects devices directly over a short range (about 10 m), using little power — e.g. headphones, keyboards and speakers. Low bandwidth.

Encryption

Wireless signals can be picked up by anyone in range, so data is encrypted: it's scrambled using a key, so if it's intercepted it can't be understood without the key. Wi-Fi uses encryption standards such as WPA2 and WPA3.

Common mistake

Encryption doesn't stop data being intercepted — it makes intercepted data unreadable.

1.3.2

Addresses, standards, protocols and layers

IP and MAC addresses

IP addressAssigned to a device by the network it joins, so it can change. Used to route data across networks and the Internet. IPv4: 32 bits, written as four numbers 0–255 (e.g. 192.168.1.24). IPv6: 128 bits, written in hex, because the world was running out of IPv4 addresses.
MAC addressA unique address assigned to the NIC when it's made, so it doesn't change. 48 bits, written as 12 hex digits (e.g. 3C:22:FB:9A:01:7E). Used to send data to the right device within a LAN.

Standards

Standards are agreed sets of rules for hardware and software. They mean products made by different manufacturers can work together — any Wi-Fi laptop can join any Wi-Fi network.

Protocols

A protocol is a set of rules for how data is sent between devices.

TCP/IPTCP splits data into packets, numbers them, checks they all arrive and puts them back in order (asking for missing ones to be resent). IP addresses the packets and routes them to the right destination.
HTTPUsed by web browsers to request and receive web pages from web servers.
HTTPSHTTP with encryption, so web pages and data (like passwords and card details) are sent securely.
FTPUsed to transfer files between computers, e.g. uploading a website's files to a web server.
SMTPUsed to send email to a mail server, and between mail servers.
POPUsed to download email from a mail server to one device; it's then usually deleted from the server.
IMAPUsed to access email that stays on the server, so it's the same on every device.

Layers

Network communication is split into layers. Each layer is a group of related protocols that does one part of the job and passes data to the layer above or below.

ApplicationProtocols that apps use: HTTP, HTTPS, FTP, SMTP, IMAP, POP
TransportSplitting data into packets and reassembling them: TCP
InternetAddressing and routing packets between networks: IP
LinkSending data over the physical connection: Ethernet, Wi-Fi

Why use layers?

  • Each layer is self-contained, so it can be developed or changed without affecting the others.
  • Developers can focus on one layer without needing to understand them all.
  • Problems are easier to find and fix.
  • Standards for each layer let hardware and software from different manufacturers work together.

The GCSE Revision Console has more practice on protocol layers.

Common mistake

SMTP sends email; POP and IMAP receive it. And "HTTPS is secure" isn't enough — say it encrypts the data.
