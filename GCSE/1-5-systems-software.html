Systems software

The software that runs the computer itself rather than doing a job for the user: the operating system, which manages the hardware, and utility software, which keeps the computer running well.

1.5.1

The operating system and user interface

An operating system (OS) is software that manages the computer's hardware and software, and provides a platform for applications to run on. Windows, macOS, Linux, Android and iOS are all operating systems. You need to know five functions:

  1. Providing a user interface
  2. Memory management and multitasking
  3. Peripheral management and drivers
  4. User management
  5. File management

User interface

The OS provides a way for the user to interact with the computer.

GUIGraphical user interfaceWindows, icons, menus and a pointer. Easy to learn and use, so it suits most users and beginners. Uses more memory and processing power.
CLICommand-line interfaceThe user types commands. Hard to learn because you must remember the commands, but fast and powerful for experts (e.g. network technicians) and uses very few resources.
Menu-drivenThe user picks from a series of simple menus, e.g. a cash machine or a car's settings screen. Very easy, but limited options.
1.5.1

Memory management and multitasking

When a program runs, it must be loaded into RAM. The OS's memory management:

  • Allocates space in RAM to each program and its data
  • Keeps track of which parts of memory are being used by which program
  • Stops programs overwriting each other's memory
  • Frees up memory when a program closes
  • Moves data between RAM and virtual memory when RAM is full (see 1.2)

Multitasking means running more than one program at the same time. A CPU core can only process one instruction at a time, so the OS switches between programs very quickly, giving each a short slice of CPU time. This happens so fast that the programs appear to run simultaneously.

Common mistake

Multitasking on one core doesn't run programs at exactly the same instant — the OS switches between them so quickly that it looks that way.

1.5.1

Peripheral management and drivers

Peripherals are devices connected to the computer, such as keyboards, mice, printers, webcams and speakers. The OS manages communication with them: sending data to output devices, receiving data from input devices, and handling things like the print queue.

Every model of printer or graphics card works slightly differently, so the OS uses device drivers. A driver is a small piece of software that translates the OS's general instructions into the specific commands that a particular device understands (and translates the device's signals back for the OS).

This means the OS doesn't need to know how every device works: it can use hardware from any manufacturer as long as there's a driver. When you plug in a new device, the OS installs its driver; drivers are updated to fix bugs or add features.

In the exam

"A driver lets the computer use the printer" isn't enough. Say it translates instructions between the operating system and the device.

1.5.1

User management and file management

User management

  • Creates and deletes user accounts, each with a username and password to log in (authentication)
  • Sets access rights (permissions): which files, folders and programs each user can read, change or delete
  • Keeps each user's files and settings separate (their own profile)
  • Can monitor log-ins and lock accounts after repeated failed attempts

File management

  • Organises files into folders (directories) in a hierarchy, so they're easy to find
  • Lets users create, name, rename, open, save, copy, move and delete files
  • Keeps track of where each file is stored on the storage device
  • Applies file permissions, e.g. making a file read-only

1.5.2

Utility software

Utility software performs specific tasks to help maintain, protect or improve the performance of the computer.

Encryption softwareScrambles files or whole drives using a key, so that if a device is lost or stolen the data can't be read without the key.
DefragmentationReorganises files on a hard disk drive so that each file's parts are stored next to each other, which makes files faster to read.
Data compressionReduces the size of files so they take up less storage space and are quicker to send (see lossy and lossless in 1.2).

How fragmentation happens

When files are saved, deleted and made bigger, the gaps left on a hard disk are different sizes. A new file may not fit in one gap, so it's split into fragments stored in different places. To read the file, the disk's read/write head has to move to each fragment in turn, which takes time.

Defragmentation moves the fragments so each file is stored in one continuous block, and gathers the free space together. The head moves less, so files load faster.

Common mistakes

  • Defragmentation doesn't create more storage space or delete files — it rearranges them.
  • SSDs should not be defragmented. They have no moving parts, so data can be read equally fast wherever it's stored — there's no benefit — and the extra writing wears out their memory cells, which have a limited number of write cycles.

Going further · grades 8–9

Backup software is another common utility. A full backup copies everything, which is simple to restore but slow and uses lots of space. An incremental backup copies only what has changed since the last backup, which is quick and small, but restoring needs the full backup plus every incremental one since.
