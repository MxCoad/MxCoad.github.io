💾 Binary Lab

Computers store everything — words, pictures, numbers — as 1s and 0s. Have a go!

Type your first name. Each letter is stored as 8 bits (a byte). Tap the bits to change a letter!

Your name

Each letter = 8 bits = 1 byte. Computer Science open evening.

A picture is a grid of tiny squares called pixels. Tap the squares to draw — and watch the numbers the computer would store.

Make the target number by switching bits on. Each bit is worth double the one on its right!
